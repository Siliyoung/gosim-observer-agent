# Experiment E010

## Source

Pandora schedule optimization, arXiv:2305.02285.

## Hypothesis

Reducing initial request value from 50% to 40%, while retaining 100% at deadline, will preserve L4 robustness and recover L1 science.

## Change

Changed request urgency from `0.50 + 0.50 * deadline_term` to `0.40 + 0.60 * deadline_term`.

## Results

| L3 | 4691.631469 | 4691.631469 | 0.000000 |
| L4 | 4160.179962 | 4160.297389 | +0.117427 |

## Diagnostics

- robust objective: 4496.231815 -> 4495.432089
- required miss: 8 -> 8; invalid action: 0; request miss: 4/8
- avoidable wait: unavailable; worst improved only 0.117427

## Analysis

The variant was nearly equivalent but lost enough L2 score to miss the robust best.

## Decision

REJECT

## Lesson

The 50% initial request value is slightly more robust than 40%.
