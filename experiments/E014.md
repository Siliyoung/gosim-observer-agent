# Experiment E014

## Source

Shetrone et al. (2007), weather- and condition-aware queue scheduling.

## Hypothesis

Removing `rocket_launch` from the adverse-forecast direction set will avoid overreacting to a rare event and improve useful observing time.

## Change

Removed `rocket_launch` from the deterministic adverse-forecast direction set. No other planner logic changed.
