# Experiment E005

## Source

Shetrone et al., *Ten Year Review of Queue Scheduling of the Hobby-Eberly Telescope*, arXiv:0705.3889.

## Hypothesis

Using tonight's public forecast deterministically in rule-only mode to avoid adverse compass directions will improve valid science and required completion.

## Change

Added rule-only direction avoidance for forecast `rain`, `storm`, `overcast`, `haze`, and `rocket_launch`; `ALL` forecasts do not force closure.

## Diagnostics

- robust objective: 4385.768090 -> 4466.636429
- mean / worst: 4563.835163 / 3998.802359 -> 4654.893466 / 4031.382814
- required miss: 11 -> 10
- invalid action: 0; request miss: 4/8; avoidable wait: unavailable
- other: L1 also obtained a correct +100 report; all four cards improved

## Analysis

The rule-only path had stored forecasts but discarded them when LLM was disabled. A small deterministic feature closed that gap and improved every card.

## Decision

KEEP

## Lesson

Public forecast direction is a strong general feature; an LLM is not required to exploit it.
