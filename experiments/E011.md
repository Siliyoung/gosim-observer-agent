# Experiment E011

## Source

Foote et al. (2023), rolling-horizon deadline scheduling for Pandora.

## Hypothesis

Raising the initial active-request urgency from 0.50 to 0.55 while retaining the final-night value of 1.00 will improve request completion without harming the four-card robust objective.

## Change

Changed the lower endpoint of the request urgency ramp from 0.50 to 0.55. No other planner parameter changed.

## Results

|---|---:|---:|---:|
| L1 | 4728.527875 | 4625.197659 | -103.330216 |
| L2 | 5032.127829 | 5032.127829 | 0.000000 |
| L3 | 4691.631469 | 4691.631469 | 0.000000 |
| L4 | 4160.179962 | 4160.306379 | +0.126417 |

Robust objective: 4496.231815 → 4471.971143.

## Diagnostics

- required miss: 8 total, unchanged
- invalid action: 0
- avoidable wait: unavailable from the V4 runner
- request miss: 4 of 8, unchanged
- flexible shortfall: unavailable from the V4 runner

## Analysis

The slightly stronger request pressure changed the L1 trajectory enough to lose substantially more science value, while producing no additional request completion. The tiny L4 gain does not compensate for the L1 loss.

## Decision

REJECT

## Lesson

The 0.50 initial request weight is a better local operating point than 0.55; request pressure is highly path-dependent even when completion counts do not change.
