# Experiment E006

## Source

Foote et al., Pandora schedule optimization, arXiv:2305.02285.

## Hypothesis

Valuing a new active request at 50% of reward-per-needed-target, rising to 100% inside 24 hours, will improve deadline scheduling without overtaking required priority.

## Change

Changed request urgency from `0.15..0.50` to `0.50..1.00`.

- required miss: 10 -> 8 (L4: 4 -> 2)
- invalid action: 0; request miss: 4/8 -> 4/8; avoidable wait: unavailable
- science/base: L1 4630.760309, L2 4987.437494, L3 4646.568489, L4 4171.071058

## Analysis

No additional request completed. The higher value changed early trajectories and substantially improved L4 required completion and the worst-card score, while sacrificing L1. The robust objective and worst card both improved, so this is a useful generalization trade-off.

## Decision

KEEP

## Lesson

Moderate request-aware receding-horizon pressure can improve global robustness even when the binary request reward itself remains unreachable.
