# Experiment E003

## Source

Foote et al., *Schedule optimization for transiting exoplanet observations with NASA's Pandora SmallSat mission*, arXiv:2305.02285.

## Hypothesis

Adding urgency inversely proportional to remaining visible nights for unfinished required targets will reduce required misses.

## Change

Added `3 / nights_left` to shortlist urgency for unfinished required targets.

## Results

## Diagnostics

- robust objective: 4385.768090 -> 4385.768090
- required miss: 11 -> 11
- invalid action: 0; request miss: 4/8; avoidable wait: unavailable
- other: every score, science component, and action count was identical

## Analysis

The existing required bonus already dominated shortlist ordering, so another multiplicative urgency term did not change a decision.

## Decision

REJECT

## Lesson

Required misses are not caused by catalogue shortlist rank at this weight level.
