# Experiment E002

## Source

Rothchild, Stubbs, and Yoachim, *ALTSched: Improved Scheduling for Time-Domain Science with LSST*, arXiv:1903.00531. The paper motivates controlling myopic one-step merit changes because they can produce inferior long-horizon schedules.

## Hypothesis

Accepting local field refinement only when estimated field value improves by at least 0.5% will suppress trajectory changes caused by numerical micro-gains, recover most of L4, and retain most gains on L1-L3 without any card identity.

## Change

- Removed the card-ID branch.
- Added a universal 0.5% minimum relative-value improvement for accepting a locally refined pointing.
- Removed the now-unused `card_id` field from Agent state.

## Analysis

The margin substantially reduced E001's L4 regression, showing that small local improvements were destabilizing. A fixed one-step margin nevertheless lost broad science on L1/L2 and did not protect required completion. The original raw baseline is ineligible because it violates the no-card-hardcoding constraint, so this is retained only as the strongest tested compliant starting point, not claimed as a metric improvement over the raw baseline.

## Decision

KEEP (compliance baseline)

## Lesson

Future experiments must improve from the compliant 4385.768090 baseline. Opportunity cost should be represented through observable urgency, deadlines, density, or remaining windows rather than a card name.
